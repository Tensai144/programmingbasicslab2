### 1. Постановка задачи

> Напишите программу на Java, которая выполняет следующие действия
> с двумерным массивом температур:
> 1. Считывает с консоли размеры массива `N` и `M`, затем элементы
> массива размером `N × M`, где каждый элемент — температура в
> точке `(x, y)`. Затем считывает число `T`.
> 2. Сортирует столбцы массива по возрастанию количества точек с
> температурой ниже заданного значения `T` в каждом столбце. Если
> количества равны, сортирует по количеству точек с температурой
> выше `T`.
> 3. Находит и выводит самую часто встречающуюся температуру в
> массиве. Если таких температур несколько, выводит наименьшую.
> 4. Выводит элементы массива в виде спирали, начиная с центрального
> элемента и двигаясь против часовой стрелки.
> 5. Заменяет в массиве все температуры ниже заданного значения `T`
> на `T` и выводит обновлённый массив.

### 4. Математическая модель

Пусть задана матрица температур $$A$$ размером $$N \times M$$ с элементами $$a_{i, j}$$, где $$i \in [0, N - 1]$$ — индекс строки, $$j \in [0, M - 1]$$ — индекс столбца, а также пороговое значение $$T \in \mathbb{R}$$.

1. **Критерии сравнения столбцов при сортировке:**
   Для каждого столбца $$j$$ определяются две характеристики:
   - Количество элементов строго ниже $$T$$:
     $$B(j) = \sum_{i=0}^{N-1} [a_{i, j} < T]$$
   - Количество элементов строго выше $$T$$:
     $$U(j) = \sum_{i=0}^{N-1} [a_{i, j} > T]$$

   Столбец $$j_1$$ считается «меньше» столбца $$j_2$$ и располагается левее него, если выполняется условие:
   $$(B(j_1) < B(j_2)) \lor (B(j_1) = B(j_2) \land U(j_1) < U(j_2))$$

2. **Поиск моды (самой частой температуры):**
   Для каждого уникального значения $$x \in A$$ вычисляется частота его вхождения $$f(x)$$. Искомое значение $$x^*$$ удовлетворяет условию:
   $$x^* = \min \{ x \mid f(x) = \max_{y \in A} f(y) \}$$

3. **Координаты стартовой точки спирали:**
   Начальная точка обхода задается целочисленным делением размеров матрицы пополам:
   $$i_0 = \left\lfloor \frac{N}{2} \right\rfloor, \quad j_0 = \left\lfloor \frac{M}{2} \right\rfloor$$

4. **Пороговая фильтрация элементов:**
   Каждый элемент матрицы обновляется по правилу:
   $$a'_{i, j} = \max(a_{i, j}, T)$$

### 5. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:**
   Программа считывает с клавиатуры два целых числа `n` и `m` — размеры двумерного массива. Затем создается массив `temperatures` размером `n × m`, и с помощью вложенных циклов в него считываются `n * m` вещественных чисел. После этого считывается вещественное число `t`.

2. **Сортировка столбцов:**

   2.1. **Вспомогательные методы:**
   Метод сортировки `selectionSort` использует 3 вспомогательных метода: `countTempAbove`, `countTempBelow` и `changeColumns`. Первые два метода проходят циклом по заданному столбцу матрицы, сравнивая каждый элемент с `t`, и возвращают счетчик `count` типа `int` (количество элементов с температурой выше или ниже `t`). Третий метод поэлементно меняет местами два указанных столбца матрицы.

   2.2. **Основной метод сортировки (`selectionSort`):**
   Используется алгоритм **сортировки выбором**, так как он минимизирует количество тяжелых операций обмена столбцов в двумерном массиве (максимум `m - 1` обмен вместо `m * (m - 1) / 2` в сортировке пузырьком).

   Проходим по всем `m - 1` столбцам. На каждом шаге за начальный минимум берем текущий столбец: записываем его индекс в `minInd`, а количество температур выше и ниже `t` — в `minAbove` и `minBelow`. Далее проходим по всем столбцам правее текущего, вычисляем для каждого `currBelow` и `currAbove` и сравниваем с текущим минимумом. Если `minBelow > currBelow` ИЛИ (`minBelow == currBelow` И `minAbove > currAbove`), обновляем параметры минимума. После внутреннего цикла, если `minInd` изменился, меняем текущий столбец с найденным минимальным.

3. **Поиск самой часто встречающейся температуры (`mostFrequent`):**
   Создается одномерный массив `list` размером `n * m`, в который переписываются все элементы матрицы. Далее массив сортируется по возрастанию с помощью стандартного метода `Arrays.sort(list)` — это гарантирует, что одинаковые температуры встанут подряд, а при равной частоте первым встретится наименьшее значение.

   Затем за один линейный проход по массиву `list` подсчитывается длина каждой серии одинаковых чисел (`countCurr`). Если текущая серия оказывается строго длиннее максимальной (`countCurr > maxCount`), обновляются значения `maxCount` и `mostFreq`. После окончания цикла выполняется финальная проверка для учета элементов в самом конце массива.

4. **Вывод элементов по спирали (`printSpiral`):**
   Вычисляются координаты центра матрицы: `line = n / 2` и `column = m / 2`. Выводится центральный элемент, а счетчик выведенных элементов `countPrinted` устанавливается в `1`.

   Далее в цикле `while (countPrinted < total)` выполняется движение против часовой стрелки по четырем направлениям в строгом порядке: **влево → вниз → вправо → вверх**. Начальная длина шага `stepLength` равна `1`. После каждых двух направлений (после движения вниз и после движения вверх) длина шага увеличивается на `1`. На каждом шаге проверяется, не вышли ли координаты за границы матрицы (`0 <= line < n` и `0 <= column < m`). Если координаты корректны, элемент выводится на экран и счетчик `countPrinted` увеличивается.

5. **Замена температур ниже `T` (`changeToMiddleTemp`):**
   С помощью вложенных циклов программа проходит по всем строкам и столбцам матрицы. Если значение текущего элемента строго меньше `t`, оно заменяется на `t`. После этого обновленная матрица выводится на экран методом `printMatrix`.
