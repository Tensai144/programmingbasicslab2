### 1. Постановка задачи

> Напишите программу на Java, которая выполняет следующие действия
> с двумерным массивом температур:
> 1. Считывает с консоли размеры массива `N` и `M`, затем элементы
> массива размером `N × M`, где каждый элемент — температура в
> точке `(x, y)`. Затем считывает число `T`.
> 2. Сортирует столбцы массива по возрастанию количества точек с
> температурой ниже заданного значения `T` в каждом столбце. Если
> количества равны, сортирует по количеству точек с температурой
> выше `T`.
> 3. Находит и выводит самую часто встречающуюся температуру в
> массиве. Если таких температур несколько, выводит наименьшую.
> 4. Выводит элементы массива в виде спирали, начиная с центрального
> элемента и двигаясь против часовой стрелки.
> 5. Заменяет в массиве все температуры ниже заданного значения `T`
> на `T` и выводит обновлённый массив.

#### Логика решения

**1. Сортировка:** В нашем случае сортировку с условием можно свести к обычной сортировке, поняв, как правильно сравнивать элементы (столбцы): один столбец меньше другого, если у него значение кол-ва точек с температурой ниже `T` меньше, чем у второго ИЛИ меньше значение кол-ва точек,
 с температурой выше `T`, если первое значение равно у обоих столбцов. В качестве алгоритма сортировки можно выбрать сортировку выбором. Почему? По сравнению с сортировкой пузырьком, кол-во сравнений у нас примерно одинаковое, однако в сортировке выбором мы за 1 проход меняем столбцы не более одного раза, в то время как в сортировке пузырьком каждый раз, когда правый элемент меньше левого. В нашем случае мы обмениваем столбцы поэлементно, т.е кол-во операций многократно увеличивается, по сравнению с обычной заменой элементов массива. Быстрая же сортировка избыточна в данной задаче, поскольку использует доп. память и сложна в написании.
 
 **2. Самая часто встречающаяся температура:** Можно перезаписать все элементы матрицы во временный одномерный массив и отсортировать его по возрастанию. Тогда мы получим массив, в котором все одинаковые элементы идут подряд, а если какие-то 2 элемента встречаются одинаковое количество раз, то первым мы подберем меньший из них.
 
 **3. Вывод по спирали:** Будем менять направления по кругу (влево - вниз - вправо - вверх) и каждые два поворота увеличивать длину шага (кол-во элементов на одном направлении, которое мы напечатаем за проход) на 1. На каждом шаге проверяем, не вышли ли мы за границы массива. Останавливаемся, как только выведем все `N × M` элементов.
 
 **4. Замена температур:** Проходим по всем элементам матрицы. Если значение текущего элемента меньше `t`, оно заменяется на `t`.

### 4. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:**
   Программа считывает с клавиатуры два целых числа `n` и `m` — размеры двумерного массива. Затем создается массив `temperatures` размером `n × m`, программа считывает `n * m` чисел и заполняет ими массив. После этого считывается вещественное число `t`.

2. **Сортировка столбцов:**

   2.1. **Вспомогательные методы:**
   Метод сортировки `selectionSort` использует 3 вспомогательных метода: `countTempAbove`, `countTempBelow` и `changeColumns`. Первые два метода проходят циклом по заданному столбцу матрицы, сравнивая каждый элемент с `t`, и возвращают счетчик `count` типа `int` (количество элементов с температурой выше или ниже `t` соответственно). 3-ий метод меняет местами `i-ый` и `j-ый` столбцы матрицы.
   
   2.2. **Сама сортировка (метод `selectionSort`):**
   Используется алгоритм **сортировки выбором**:

   Проходим по всем `m - 1` столбцам. На каждом шаге за начальный минимум берем текущий столбец: записываем его индекс в `minInd`, а количество температур выше и ниже `t` — в `minAbove` и `minBelow`. Далее проходим по всем столбцам правее текущего, вычисляем для каждого `currBelow` и `currAbove` и сравниваем с текущим минимумом. Если `minBelow > currBelow` ИЛИ (`minBelow == currBelow` И `minAbove > currAbove`), обновляем параметры минимума. После внутреннего цикла, если `minInd` изменился, меняем текущий столбец с найденным правее него минимальным.
   (Все вышеперечисленные переменные - типа данных `int`, поскольку содержат в себе индекс/счетчик)

   **Примечание:** "Минимальным" столбцом будем называть тот, у которого значение
 кол-ва точек с температурой ниже `t` минимально ИЛИ минимально значение кол-ва точек,
 с температурой выше `t`, если первое значение равно у всех столбцов

   Отсортированная матрица выводится на экран методом `printMatrix`.

3. **Поиск самой часто встречающейся температуры (`mostFrequent`):**
   Создается одномерный массив `list` типа `double[]` размером `n * m`, в который переписываются все элементы матрицы. Далее массив сортируется по возрастанию (с помощью встроенного метода `Arrays.sort`) , что гарантирует, что одинаковые температуры встанут подряд, а при равной частоте первым встретится наименьшее значение.

   Затем за один проход по массиву `list` подсчитывается длина каждой последовательности одинаковых чисел ( переменная `countCurr`). Если текущая последовательность оказывается длиннее максимальной (`countCurr > maxCount`), обновляются значения `maxCount` и `mostFreq`. В начале каждой новой последовательности сбрасываем счетчик `countCurr` до 1 после проверки на максимум. Также проверяем значение счетчика после цикла, чтобы учесть ситуацию, когда нужный нам эл-т находится в самом конце списка.
   (Переменные `countCurr` и `maxCount` - типа `int` (счетчики, макс. значение счетчика), а `mostFreq` - типа `double` (значение эл-та массива)).

   В `main` вызываем метод `mostFrequent` прямо в методе `printf()`, выводя на экран найденное значение.

4. **Вывод элементов по спирали (метод `printSpiral`):**
   Вычисляются координаты центра матрицы: `line = n / 2` и `column = m / 2`. Выводится центральный элемент, а счетчик выведенных элементов `countPrinted` становится равным `1`. (все переменные типа `int`)

   Далее двигаемся по матрице в следующем порядке: **влево → вниз → вправо → вверх**. Начальная длина шага `stepLength` равна `1`. После каждой смены двух направлений (после движения вниз и после движения вверх) длина шага увеличивается на `1`. На каждом шаге проверяем, что мы не вышли за пределы матрицы. Если все в порядке, элемент выводится на экран и счетчик `countPrinted` увеличивается на `1`. Так делаем до тех пор, пока не выведем все элементы матрицы (т.е пока счетчик `countPrinted` < `total = n * m`).

5. **Замена температур ниже `t` (метод `changeToMiddleTemp`):**
   Проходим по всем элементам матрицы. Если значение текущего элемента меньше `t`, оно заменяется на `t`.

   После этого обновленная матрица выводится на экран методом `printMatrix`.

### 5. Программа

```java
import java.util.Scanner;
import java.io.PrintStream;
import java.util.Arrays;

public class Lab2 {
    // Объявляем объект out класса PrintStream для вывода в консоль
    public static PrintStream out = System.out;
    // Объявляем объект класса Scanner для ввода данных с клавиатуры
    public static Scanner in = new Scanner(System.in);

    public static void main(String[] args) {
        // Считываем размеры двумерного массива n * m
        int n = in.nextInt();
        int m = in.nextInt();
        // Задаем наш массив температур и вводим с клавиатуры его элементы
        double[][] temperatures = new double[n][m];

        for (int line = 0; line < temperatures.length; line++) {
            for (int column = 0; column < temperatures[0].length; column++)
                temperatures[line][column] = in.nextDouble();
        }

        // Считываем значение t
        double t = in.nextDouble();

        // Вызов метода сортировки нашего массива температур
        selectionSort(temperatures, t);

        // Выводим отсортированный массив
        out.println("Отсортированная матрица температур:");
        printMatrix(temperatures);

        // Находим и выводим самую часто встречающуюся температуру
        out.println("Самая часто встречающаяся температура:");
        out.printf("%.2f \n", mostFrequent(temperatures));

        // Выводим элементы матрицы по спирали
        out.println("Элементы матрицы в виде спирали:");
        printSpiral(temperatures, n, m);

        // Заменяем в массиве все температуры ниже T на T и выводим обновленный массив
        changeToMiddleTemp(temperatures, t);
        out.println("Обновленная матрица:");
        printMatrix(temperatures);
    }
    // Метод для вывода матрицы на экран
    static void printMatrix(double[][] matrix) {
        for (int line = 0; line < matrix.length; line++) {
            for (int column = 0; column < matrix[0].length; column++) {
                out.printf("%.2f ", matrix[line][column]);
            }
            out.println();
        }
    }
    // Метод для поиска кол-ва температур выше T в i-ом столбце матрицы
    static int countTempAbove(double[][] matrix, int column, double t) {
        int count = 0;
        for (int line = 0; line < matrix.length; line++) {
            if (matrix[line][column] > t)
                count++;
        }
        return count;
    }

    // Метод для поиска кол-ва температур ниже T в i-ом столбце матрицы
    static int countTempBelow(double[][] matrix, int column, double t) {
        int count = 0;
        for (int line = 0; line < matrix.length; line++) {
            if (matrix[line][column] < t)
                count++;
        }
        return count;
    }

    // Метод для обмена столбцов матрицы
    static void changeColumns(double[][] matrix, int column1, int column2) {
        for (int line = 0; line < matrix.length; line++) {
            double temp = matrix[line][column1];
            matrix[line][column1] = matrix[line][column2];
            matrix[line][column2] = temp;
        }
    }

    // Метод для сортировки массива
    static void selectionSort(double[][] matrix, double t) {
        // Общая идея:
        // Для каждого столбца будем искать "минимальный столбец" среди всех столбцов лежащих правее
        // него и поменяем их местами. (Минимальным столбцом будем называть тот, у которого значение
        // кол-ва точек с температурой ниже T минимально ИЛИ минимально значение кол-ва точек,
        // с температурой выше T, если первое значение равно у всех столбцов)

        // Проходимся по всем m - 1 столбцам
        for (int columnCurr = 0; columnCurr < matrix[0].length - 1; columnCurr++) {

            // В качестве начального индекса минимума берем индекс текущего столбца
            int minInd = columnCurr;
            // Вычисляем кол-во эл-ов в текущем столбце, с температурой выше/ниже T
            // - это будут значения для начального минимума
            int minAbove = countTempAbove(matrix, columnCurr, t);
            int minBelow = countTempBelow(matrix, columnCurr, t);

            // Проход по всем столбцам правее текущего
            for (int columnNext = columnCurr + 1; columnNext < matrix[0].length; columnNext++) {

                // Вычисляем кол-во эл-ов в правом столбце, с температурой выше/ниже T
                int currBelow = countTempBelow(matrix, columnNext, t);
                int currAbove = countTempAbove(matrix, columnNext, t);

                // Если кол-во точек с температурой ниже T меньше значения нашего минимума,
                // то обновляем индекс и значения нашего минимума
                if (minBelow > currBelow) {
                    minInd = columnNext;
                    minBelow = currBelow;
                    minAbove = currAbove;
                }
                // То же самое делаем, если кол-во точек с температурой ниже Т совпадает
                // со значением минимума, а точек с температурой выше T меньше значения минимума
                else if (minBelow == currBelow
                        && minAbove > currAbove) {
                    minInd = columnNext;
                    minAbove = currAbove;
                }
            }

            // Если начальный минимум изменился, то меняем столбцы местами
            if (minInd != columnCurr)
                changeColumns(matrix, columnCurr, minInd);
        }
    }

    // Метод для поиска самой часто встречающейся температуры в массиве
    static double mostFrequent(double[][] matrix) {
        // Задаем одномерный массив, чтобы поместить туда все эл-ты матрицы
        double[] list = new double[matrix.length * matrix[0].length];
        int ind = 0;

        // Заполняем наш одномерный массив эл-ми матрицы
        for (int line = 0; line < matrix.length; line++) {
            for (int column = 0; column < matrix[0].length; column++) {
                list[ind] = matrix[line][column];
                ind++;
            }
        }

        // Сортируем массив по возрастанию
        Arrays.sort(list);

        // В качестве самого часто встречающегося эл-та для начала берем первый эл-т
        double mostFreq = list[0];
        // Счетчик текущего числа повторений эл-та
        int countCurr = 1;
        // Максимальное значение счетчика
        int maxCount = 1;

        for (int i = 1; i < list.length; i++) {
            // Если текущий эл-т равен предыдущему, то увеличиваем счетчик на 1
            if (list[i] == list[i - 1])
                countCurr++;
            // Иначе, если текущее значение счетчика больше максимального, то обновляем
            // наш максимум и самый часто встречающийся эл-т; сбрасываем счетчик до 1
            else {
                if (countCurr > maxCount) {
                    mostFreq = list[i - 1];
                    maxCount = countCurr;
                }
                countCurr = 1;
            }
        }

        // Проверяем значение счетчика после цикла, чтобы учесть ситуацию,
        // когда нужный нам эл-т находится в самом конце списка
        if (countCurr > maxCount)
            mostFreq = list[list.length - 1];

        return mostFreq;
    }

    // Метод для вывода эл-ов массива в виде спирали
    static void printSpiral(double[][] matrix, int n, int m) {
        // Индексы центрального эл-та матрицы
        int line = n / 2;
        int column = m / 2;

        // Общее число эл-ов в матрице
        int total = n * m;
        // Счетчик выведенных эл-ов
        int countPrinted = 1;
        // Длина шага (сколько эл-ов подряд в одном направлении надо вывести)
        int stepLength = 1;

        // Выводим центральный эл-т
        out.printf("%.2f ", matrix[line][column]);

        // Начинаем с центра и двигаемся влево - вниз - вправо - вверх
        while (countPrinted < total) {
            // Движение влево на stepLength шагов
            for (int step = 0; step < stepLength; step++) {
                column--;
                // Проверяем что не вышли за пределы значений индексов матрицы
                if (line >= 0 && line < n && column >= 0 && column < m) {
                    // Если все в порядке, то выводим текущий эл-т
                    out.printf("%.2f ", matrix[line][column]);
                    countPrinted++;
                }
            }
            // Движение вниз на stepLength шагов
            for (int step = 0; step < stepLength; step++) {
                line++;
                // Проверяем что не вышли за пределы значений индексов матрицы
                if (line >= 0 && line < n && column >= 0 && column < m) {
                    // Если все в порядке, то выводим текущий эл-т
                    out.printf("%.2f ", matrix[line][column]);
                    countPrinted++;
                }
            }

            // Увеличиваем длину шага
            stepLength++;

            // Движение вправо на stepLength шагов
            for (int step = 0; step < stepLength; step++) {
                column++;
                // Проверяем что не вышли за пределы значений индексов матрицы
                if (line >= 0 && line < n && column >= 0 && column < m) {
                    // Если все в порядке, то выводим текущий эл-т
                    out.printf("%.2f ", matrix[line][column]);
                    countPrinted++;
                }
            }
            // Движение вверх на stepLength шагов
            for (int step = 0; step < stepLength; step++) {
                line--;
                // Проверяем что не вышли за пределы значений индексов матрицы
                if (line >= 0 && line < n && column >= 0 && column < m) {
                    // Если все в порядке, то выводим текущий эл-т
                    out.printf("%.2f ", matrix[line][column]);
                    countPrinted++;
                }
            }

            // Увеличиваем длину шага
            stepLength++;
        }
        out.println();
    }

    // Метод для замены в массиве всех температур, ниже заданного значения T
    static void changeToMiddleTemp(double[][] matrix, double t) {
        for (int line = 0; line < matrix.length; line++) {
            for (int column = 0; column < matrix[0].length; column++) {
                if (matrix[line][column] < t)

            }
```
